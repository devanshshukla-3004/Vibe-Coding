# Contributing

Thanks for helping improve Vibe Coding Academy.

- Keep lessons practical, beginner-friendly, and specific.
- Include a learning goal, hands-on task, deliverable, and verification questions.
- Avoid tasks that expose credentials, private data, or unauthorized systems.
- Use relative links for repository documentation.
- Do not claim tests, deployments, or integrations passed unless they were verified.
- Keep changes scoped and explain the learner benefit in the pull request.

## Pull request checklist
- [ ] Purpose and audience are clear.
- [ ] Instructions are reproducible.
- [ ] Links and commands have been checked.
- [ ] Security and privacy implications are considered.
- [ ] Known limitations are documented.
