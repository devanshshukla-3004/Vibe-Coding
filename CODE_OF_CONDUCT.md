# Code of Conduct

We want Vibe Coding Academy to be a welcoming, respectful learning environment.

## Expected behavior
- Be respectful, constructive, and patient with beginners.
- Critique ideas and code, not people.
- Explain feedback clearly and assume good faith.
- Credit others' work and follow applicable licenses.
- Protect personal information and respect consent.

## Unacceptable behavior
Harassment, discrimination, threats, doxxing, deliberate disruption, or sharing another person's private information without permission are not acceptable.

## Reporting
Contact the repository owner through GitHub with a concise description and relevant links. Reports will be handled as discreetly as practical.
