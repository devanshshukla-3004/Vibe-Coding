# Vibe Coding — Learn by Building

A beginner-friendly collection of guides, hands-on sessions, and example projects for learning how to build software with AI.

The idea is simple: **start with a small idea, use AI as a coding partner, test what you build, and understand the result.** You do not need to know everything before you begin.

This repository is made to help friends learn at their own pace. It is a learning resource—not a course, academy, or finished software product.

## 🔁 The workflow to remember

**Idea → Plan → Prompt → Build a small part → Run → Test → Improve → Share**

1. **Define the goal.** Explain what you want to build and who will use it.
2. **Plan first.** Ask AI to outline the steps and files before it starts coding.
3. **Work in small pieces.** Avoid asking for a huge application in one prompt.
4. **Understand the changes.** Ask what each important file does and review the diff.
5. **Run and test.** Check the main flow and at least one unusual or invalid case.
6. **Improve gradually.** Fix problems before adding more features.
7. **Share honestly.** Mention what you tested and what is still incomplete.

### A prompt you can reuse

> I'm a beginner building [project idea] for [intended user]. First, help me clarify the requirements and create a short plan. Explain which files you expect to create or change. Implement only the first small step, keep the solution as simple as possible, and don't add features I didn't ask for. Then explain how I can run and test it before we continue.

## 🛡️ A few important habits

- **AI can be wrong.** Generated code may look convincing and still fail. Run it and verify the behavior.
- **Protect private information.** Never paste passwords, API keys, credentials, private records, or confidential code into prompts or commit them to Git.
- **Understand commands before running them.** Be extra careful with commands that delete files or change system settings.
- **Keep changes manageable.** Review what changed and save a working version before major edits.
- **Be honest about testing.** Don't claim something works, passes tests, or is deployed unless you have checked it yourself.
- **Keep your own judgment.** AI can help you build, but you are responsible for the code and the result.
