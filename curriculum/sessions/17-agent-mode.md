# Session 17: Use Agent Mode Deliberately

## Learning goal
Define agent scope, allowed tools, stop conditions, and review checkpoints before delegating.

## Hands-on activity
Give an agent one bounded task, inspect every changed file, run checks, and revert unnecessary edits.

## Workflow
1. Define the expected outcome and acceptance criteria.
2. Ask the assistant for a plan before delegating implementation.
3. Keep the work scoped and inspect the diff.
4. Run relevant automated and manual checks.
5. Document evidence, uncertainty, and limitations honestly.

## Deliverable
Agent task brief and reviewed diff.

## Verification
- Can you account for every accepted change and revert anything you cannot verify?
- What evidence would make you change your current conclusion?
- What is the next smallest improvement?

## Responsible AI reminder
Generated output is untrusted until reviewed. Never share secrets or private data. Do not claim a check passed unless you ran it and observed the result.
