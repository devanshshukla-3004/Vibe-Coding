# Session 15: Refactor Safely with AI

## Learning goal
Recognize duplication, unclear names, long functions, and unnecessary complexity.

## Hands-on activity
Ask for a refactor plan first, preserve behavior, and run tests after each change.

## Workflow
1. Define expected behavior and acceptance criteria.
2. Ask the assistant for a plan and list of assumptions.
3. Implement incrementally and inspect every changed file.
4. Test normal, invalid, empty, and boundary cases where relevant.
5. Record actual results and known limitations.

## Deliverable
Before/after diff and rationale.

## Verification
- What evidence shows the refactor preserved behavior?
- Which test or observation provides the strongest evidence?
- What did you reject or change from the AI suggestion?

## Responsible AI reminder
Generated output is untrusted until reviewed. Never share secrets or private data. Do not claim a check passed unless you ran it and observed the result.
