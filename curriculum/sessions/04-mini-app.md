# Session 4: Build a Tiny Useful App

## Learning goal
Break a small app into interface, behavior, and data requirements.

## Hands-on activity
Build a to-do list, notes page, or unit converter in small increments; test after each change.

## Workflow
1. Write expected behavior before prompting.
2. Ask for a short plan and clarify assumptions.
3. Implement one small slice at a time.
4. Inspect the diff and explain important changes.
5. Run relevant checks and record the observed outcome.

## Deliverable
Working mini-app with a concise README.

## Verification
- Can a new user run it and complete the main task?
- What edge case did you test?
- What can you explain independently?

## Responsible AI reminder
Generated code is untrusted until reviewed. Never share credentials or private data. Do not claim a check passed unless you ran it and observed the result.
