# Six-Week Roadmap

## Outcome
Plan, build, test, explain, and present a small software product while using AI coding tools critically and responsibly.

| Week | Sessions | Focus | Milestone |
|---|---:|---|---|
| 1 | 1–4 | Setup, prompting, code reading | Working mini-app |
| 2 | 5–8 | Accessible UI, CSS, JavaScript, debugging | Responsive interactive interface |
| 3 | 9–12 | Data, APIs, persistence | Study Planner MVP |
| 4 | 13–16 | Git, tests, refactoring, security | Tested and reviewed app |
| 5 | 17–20 | Agents, verification, integrations, automation | Bounded agent task and guarded workflow |
| 6 | 21–24 | Capstone, release, demo | Documented project ready to present |

## Suggested cadence
Complete four sessions per week. Split a session across multiple study blocks when needed; understanding and evidence matter more than speed.

## Definition of done
- Deliverable exists and can be demonstrated.
- You can explain the key code and decisions in your own words.
- Relevant checks were run and outcomes recorded honestly.
- Setup and known limitations are documented.
- No credentials or private data were committed.

## Assessment rubric
- Problem framing: 20%
- Implementation: 25%
- Verification and testing: 25%
- Code understanding: 15%
- Documentation and responsible AI use: 15%
