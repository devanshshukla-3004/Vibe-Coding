# Break the AI: Verification Lab

## Objective
Treat generated claims as hypotheses that need evidence.

## Exercises
1. Ask for a possibly nonexistent library function; check official docs and a minimal executable example.
2. Give incomplete requirements; ask the model to identify assumptions and uncertainties.
3. Introduce a harmless bug; compare the model's diagnosis with logs and a minimal reproduction.
4. Ask for a security review of a toy form; independently validate each finding.
5. Verify citations by opening sources and checking that they support the claim.
