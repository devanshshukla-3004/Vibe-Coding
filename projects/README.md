# Projects

Projects reinforce the current week's skills and produce something demonstrable.

1. **Mini-app (sessions 1–4):** one useful interaction.
2. **Responsive interface (sessions 5–8):** accessible UI with clear states.
3. **Study Planner (sessions 9–14):** a runnable browser-based task manager with validation, local persistence, filtering, sorting, and unit tests. See [setup and verification](study-planner/README.md).
4. **Capstone (sessions 21–24):** a focused MVP for a real user problem.

Use the [project brief](../templates/PROJECT-BRIEF.md) before starting. Keep scope small enough to test thoroughly. Treat a CI run or a local test result as evidence; the presence of tests alone does not mean they passed.
