# Projects

Projects reinforce the current week's skills and produce something demonstrable.

1. **Mini-app (sessions 1–4):** one useful interaction.
2. **Responsive interface (sessions 5–8):** accessible UI with clear states.
3. **Study Planner (sessions 9–14):** validated task data, persistence, tests, and documented behavior.
4. **Capstone (sessions 21–24):** a focused MVP for a real user problem.

Use the [project brief](../templates/PROJECT-BRIEF.md) before starting. Keep scope small enough to test thoroughly.
