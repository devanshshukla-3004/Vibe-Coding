# Example Projects

Use these projects to learn by reading, running, changing, and rebuilding—not just by copying code.

## Suggested order

1. **Your first mini-project:** follow [Build Your First Mini-Project](../guides/FIRST-PROJECT.md). It starts with a small personal links page.
2. **Study Planner:** a browser-based task manager with task titles, due dates, priorities, completion, filtering, and browser-local persistence. Follow [the project README](study-planner/README.md) to run it and inspect how it works.
3. **Your own idea:** use the [Build Your Own Project guide](../guides/BUILD-YOUR-OWN-PROJECT.md) and the [project brief template](../templates/PROJECT-BRIEF.md).

## How to learn from an example

- First, run it and describe what each main part does.
- Pick one small improvement before asking AI to change anything.
- Ask the AI to explain its plan and which files it will edit.
- Review the diff, run the checks, and manually test the changed behavior.
- Keep a short note of what you learned and what still confuses you.

Don't copy secrets into prompts or claim a project works just because the code was generated. The project is yours to understand and verify.
